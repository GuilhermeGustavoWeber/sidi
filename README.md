# SIDI - Copiloto Cognitivo Pessoal

Sistema operacional cognitivo para Guilherme Gustavo Weber com persistencia de memoria em quatro camadas, ativacao sinaptica Hebbiana e auditoria pre-frontal estrita.

## Tecnologias e Stacks
- **Core Engine**: Python 3.11+ (modular, tipagem estrita, gerenciado via uv).
- **Interfaces e Aplicacoes**: TypeScript + HTML/CSS.
- **Persistencia**: SQL e Markdown contextual.
- **Integracao de Sistema**: C# (.NET / Windows API).

## Comandos Operacionais

```powershell
# Verificar estado do cerebro e do repositorio
python sidi.py status

# Inicializar sessao de trabalho com meta
python sidi.py boot --project core --goal "Construcao de novos servicos"

# Consulta cognitiva e auditoria de seguranca
python sidi.py think "qual a regra sobre expor credenciais em commits"

# Criar checkpoint semantico e sincronizar com Git
python sidi.py checkpoint "feat(engine): integracao do roteador pre-frontal"
```
